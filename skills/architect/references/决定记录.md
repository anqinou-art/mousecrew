# 决定记录（第 7 步）

「当初为什么这么定」，三个月后要查得到。来查的人多半是失忆之后的你自己。

## 什么时候必须写一条

- 不可逆的（数据格式、对外接口、选了哪个底座）。
- 有取舍的（两条路各有代价，你选了一条）。
- 人拍的板。

## 格式

```
## <日期> · <一句话标题>
背景：为什么要做这个决定
决定：选了什么
放弃了：另外几条路，各自为什么不选
代价：这个选择要付出什么（必须写，写不出代价说明没想清楚）
谁定的：人的原话 / 我的推论
```

## 规矩

- **署名只跟原话走。** 「人定的」只能盖在人真拍过的那一条上；你多推的那一步标成推论。借人的权威给你的判断背书，下游没有人会再去查。
- 写进变更日志 / 决定记录 / 快照——**不写进代码注释**。注释只写非显然的 WHY（藏着的约束、微妙的不变量、绕开某个具体 bug）；「给 X 用的」「为 Y 流程加的」这种注释会随代码演化烂成假路标。
- 人分开跟几只鼠聊时，「定了」只在公共的地方算数。谁听到谁去落一句原话。
